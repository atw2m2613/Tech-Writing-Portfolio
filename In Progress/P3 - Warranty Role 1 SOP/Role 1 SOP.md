# Role 1

The purpose of this role is to handle intake, create tickets, confirm applicable warranty, parts availability,
and key orders for licensed HVAC technicians.

---

## Step One: Intake

### Review E-mail for Required Information

Upon receipt of the e-mail, confirm the following information [NOTE: Items marked with an * are required for warranty verification]:
  - Homeowner Name*
  - Physical address where the equipment is installed
  - State (from physical address)*
  - Install Date*
  - Model & Serial Number for affected equipment*
  - Part Needed & Defect
  - Servicer Information

If the required items are provided, you can continue to confirming warranty, however, please note that all items are required before an order can be placed.

If the required information has not been provided, request it before proceeding.
    
    If you must request information, it is best to go ahead and request anything that is missing 
    upfront, if possible.

### Confirm Equipment Warranty

Once the required information has been reviewed, you will need to navigate to the applicable manufacturer website. At this time, we only handle two systems: RHE MFG and CAR MFG. 

Each manufacturer has their own way of handling information and require different information to confirm warranty. Typically, as long as the required information has been received, you can still proceed with this step for both manufacturers.

#### RHE MFG Warranty Confirmation

Navigate to the RHE MFG website (link) and login to the warranty section. Once logged in, select "WARRNTY ENTITLEMENT" from the left hand menu.

Enter the required information and select "Check Warranty":
- Serial Number
- Homeowner's Last Name
- State

The screen should display the following information:
- Homeowner Information
  - If registered, this information will be filled in.
  - If not registered, it will be blank.
- Original Distributor
  - It will usually only list the company it was sold to, the manufacturer SKU number, and the model number for the equipment.
- Warranty Information
  - If registered, than the start date listed will be accurate.
  - If it is not registered, then the listed start date is when the equipment was shipped to the distributor by the manufacturer. You will need to refer to the provided install date in order to confirm coverage start date.
